# Tang Primer 25K + PMOD-AUDIO : Intel-style chime

## ファイル構成
- `top.sv` — トップモジュール（クロック・リセット・出力ピンの接続のみ）
- `por_reset.sv` — 電源投入リセット生成（同期リセット、`initial`不使用）
- `jingle_player.sv` — 音階シーケンサ＋ウェーブテーブル音源（DDS位相アキュムレータ＋倍音構成波形ROM＋アタック/ディケイ・エンベロープ）＋リバーブ＋8bit PWM DAC
- `reverb.sv` — 3並列コムフィルタ＋直列オールパスフィルタによる本格的なリバーブ（Freeverb方式）
- `comb_filter.sv` — ローパスフィードバック・コムフィルタ（BRAM遅延ライン使用）
- `allpass_filter.sv` — オールパスフィルタ（BRAM遅延ライン使用、拡散用）
- `top.cst` — Gowin物理制約ファイル
- `top.sdc` — 50MHzクロックのタイミング制約

## 設計判断・前提条件（要確認）
1. **システムクロックピン**: 依頼文に具体的なピン番号の記載が無かったため、Tang Primer 25Kコアボードのオンボード発振器ピン **E2**（50MHz）を前提にしました。実機のスケマティックと異なる場合は `top.cst` の `IO_LOC "clk" E2;` を修正してください。
2. **音声出力**: 物理制約表で `Port1(G11)` のみ `Input_L` と明記されていたため、モノラル1本（G11）のみを駆動する設計にしています。PMOD-AUDIO v1.2のスケマティック（J1コネクタ）を確認したところ、ピン1=IL、ピン2=IRで、オンボードのRPフィルタ経由でPAM8403アンプ（ヘッドホン/スピーカー出力）に入っています。ステレオ化したい場合はPort2(D11)に同じ信号（またはIR用の別出力）を追加接続してください。
3. **リバーブ**: 波形ROM＋エンベロープだけでは物理的な残響は作れないため、`reverb.sv`としてBRAM遅延ライン＋フィードバックによる本格的なリバーブを追加しました（Freeverb方式の簡易版）。
   - **コムフィルタ×3並列**（`comb_filter.sv`）: 遅延長 1116 / 1277 / 1422サンプル（約48kHzサンプルレートで約23〜30ms）。フィードバックゲイン≈0.84、フィードバック経路にワンポール・ローパス（ダンピング係数≈0.20）を挿入し、高域を減衰させながら響かせています。遅延ラインはGowinでBRAMとして推論されるサイズです
   - **オールパスフィルタ×1**（`allpass_filter.sv`、直列）: 遅延長556サンプル、ゲイン0.5。コムフィルタ特有の金属的な響きを拡散・緩和します
   - **ドライ/ウェットミックス**: `reverb.sv`内でドライ信号35%・リバーブ信号65%にブレンド（`DRY_GAIN_Q8`/`WET_GAIN_Q8`で調整可能）
   - 各フィルタは`smp_en`（約48kHz）に同期した2クロックのパイプライン遅延を持ちますが、オーディオサンプル周期（1000クロック以上）に対して無視できるレベルです
   - 遅延ラインのBRAMは`initial`による初期化を行っていないため、電源投入直後は内容が不定です。フィードバックゲインが1未満なので実害はありませんが、起動直後の数秒間はごく微弱なノイズ成分がリバーブテールに乗り、自然に減衰して消えていきます
4. **駆動方式**: 単純な矩形波（1ビットトグル出力）ではなく、以下のウェーブテーブル音源＋PWM DACを使用しています。
   - **波形ROM**: 1・2・5・7・9・11倍音を強め、その間の倍音を弱めた「まばらな倍音構成」の256サンプル単周期波形を使用（`wave_rom`関数、synthesis-safe case文）。ピアノのように滑らかに減衰する倍音列ではなく、実際のベル／チャイムに近い、飛び飛びに強いピークを持つスペクトルにしています
   - **DDS位相アキュムレータ**: 16bit、音サンプルレート約48kHzごとに`phase_inc`を加算し波形ROMを読み出し
   - **エンベロープ**: 発音開始で高速アタック（約0.7ms）→ 非常にゆっくりした指数関数的ディケイ（約1ms毎に`env -= env >> 9`、無音までおよそ2.5秒）。休符ステップに入っても最後の音（G#4）のピッチのまま発振を続けさせ、エンベロープだけが自然に減衰していくことで「余韻が響いて消えていく」感じを出しています
   - **PWM DAC**: リバーブ後のサンプルを8bit PWMデューティに変換（範囲外はクランプ処理）し、CLK/256（約195kHz）のキャリアで出力。PMOD-AUDIO側のRCフィルタでさらに平滑化されます
5. **メロディ**: 「インテル入ってる」CMで有名な5音チャイム（F#-C#-F#-C#-G#、通称"bong"）を実装しています。オクターブは4th octave（F#4≈370Hz, C#4≈277Hz, G#4≈415Hz）を仮定した近似値です。周波数（`phase_inc`）・長さ・波形・エンベロープ（アタック速度、減衰の速さ）は `jingle_player.sv` 内のパラメータ／波形ROM生成部分で自由に調整できます。残響（余韻）の長さは`DECAY_SHIFT`（大きいほど長く響く）で調整してください。
6. **再生タイミング**: リセット解除後すぐに1回再生し、末尾に2秒の無音区間を挟んで自動的にループする構成です。ボタン等のトリガ入力は制約表に含まれていなかったため未実装です。

## ビルド手順（Gowin EDA / GW5A-LV25MG121C1）
1. 新規プロジェクトを作成し、デバイスを `GW5A-LV25MG121C1/I0` に設定
2. `top.sv`, `jingle_player.sv`, `reverb.sv`, `comb_filter.sv`, `allpass_filter.sv`, `por_reset.sv` をソースに追加
3. `top.cst` をConstraintsに追加
4. `top.sdc` をSDCとして追加（Place & Route前にタイミング制約として読み込み）
5. Synthesize → Place & Route → プログラム書き込み

## 音量・配線に関する注意
- PMOD-AUDIO v1.2の3.5mmジャック出力（OUTL/OUTR）または基板上スピーカーから音が出ます。ボリュームは基板上のポテンショメータで調整してください。
